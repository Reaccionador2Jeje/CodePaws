# CodePaws 3D

The new Godot 4 project is being developed alongside the original Python/Pygame prototype while core systems are rebuilt.

## Open the project

1. Install Godot 4.3 or newer.
2. Import the `godot/project.godot` file in the Godot Project Manager.
3. Press F6/F5 (or Play Project) to run the 3D prototype.

## Current prototype

- Lightweight stylized 3D valley with a village path, pond, houses and trees.
- Third-person player controller with keyboard movement, jumping and mouse camera.
- Four procedural companion prototypes that wander around and respond to interaction.
- Compatibility renderer selected for a broad range of hardware.

## Controls

- WASD: move
- Mouse: look around
- Space: jump
- F: interact with a nearby companion
- Esc: release mouse; click to capture it again

This is an early foundation, not a finished open world. Models, animations, saving, needs, mobile controls, streaming world chunks and Steam packaging are planned for later milestones.
