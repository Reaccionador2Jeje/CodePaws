# CodePaws — mascot and logo visual references

These are visual research references for the hand-drawn 48×48 terminal sprites.
The sprites are original small-scale interpretations of the visual references,
not copied source images. Some catalog entries are logos or original CodePaws
companions rather than official mascots; that distinction is recorded below.

| CodePaws pet | Reference | What the reference establishes |
|---|---|---|
| Py — Python | [Python Software Foundation logo resources](https://www.python.org/community/logos/) | Blue and yellow interlocking snake mark. Python has no official animal mascot. |
| Ferris — Rust | [Rustacean.net — original Ferris artwork](https://www.rustacean.net/) · [Rust artwork repository](https://github.com/rust-lang/rust-artwork) | Orange crab silhouette, shell, eyes and pincers. Ferris is Rust's unofficial community mascot; the original artwork is dedicated to CC0 where possible. |
| Gopher — Go | [The Go Gopher — official Go blog](https://go.dev/blog/gopher) | Renée French's gopher: blue rounded body, large eyes, ears, muzzle and front teeth. Go gopher artwork is CC BY 4.0; credit Renée French. |
| Duke — Java | [Dev.java — Duke, the Java mascot](https://dev.java/duke/) · [OpenJDK Duke gallery](https://wiki.openjdk.org/spaces/duke/pages/51282071/Gallery) | White character, pointed dark head and red nose. Java community material states that Duke was open-sourced under BSD; check individual assets before redistribution. |
| Moby — Docker | [Docker — Call me Moby Dock](https://www.docker.com/blog/call-me-moby-dock/) · [Docker trademark guidelines](https://www.docker.com/legal/trademark-guidelines/) | Blue whale carrying shipping containers. Docker's guidelines restrict imitations and reproductions of its character/logo; CodePaws uses an original educational interpretation, not official Docker artwork. |
| Octocat — GitHub | [GitHub Brand Toolkit — mascots](https://brand.github.com/graphic-elements) · [GitHub Brand Toolkit — logo](https://brand.github.com/foundations/logo) | Cat/octopus concept. GitHub's current primary mascot is Mona; Octocat is the historic name/style. Brand assets are trademarks and must not imply endorsement. |
| Tanuki — GitLab | [GitLab Pajamas — Tanuki logomark](https://design.gitlab.com/brand-logo/logomark/) | Geometric tanuki/infinity-loop mark in orange and yellow. This is a logomark, not a detailed cartoon animal. |
| ElePHPant — PHP | [PHP.net — ElePHPant](https://www.php.net/elephpant.php) · [Wikimedia Commons — ElePHPant artwork](https://commons.wikimedia.org/wiki/File:Webysther_20160423_-_Elephpant.svg) | Blue elephant mascot with large ears and trunk. Original character credited to Vincent Pontier. |
| Javie — JavaScript | [JavaScript JS logo reference](https://2ality.com/2011/10/logo-js.html) | Yellow square with dark “JS” monogram. JavaScript has no universally recognized official animal mascot; Javie is an original CodePaws companion. |
| Tessa — TypeScript | [TypeScript logo — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Typescript.svg) | Blue square with white “TS” monogram. TypeScript has no official animal mascot; Tessa is an original CodePaws companion. |
| Ruby — Ruby | [Ruby Association — official logo](https://www.ruby.or.jp/en/about/logo) · [Ruby language logo](https://www.ruby-lang.org/en/about/logo/) | Red gemstone mark. Ruby has a logo, not a canonical official animal mascot. |
| Cee — C | [C Language logo — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:C_Language_Logo.svg) | Blue hexagonal badge with a white C. C has no canonical official mascot; Cee is an original CodePaws companion. |
| PlusPlus — C++ | [C++ Institute — brand resources](https://cppinstitute.org/brand-resources) | C++ identity reference. C++ has no canonical official mascot; PlusPlus is an original CodePaws companion. |
| Kodee — Kotlin | [Kotlin brand assets — official mascot](https://kotlinlang.org/docs/kotlin-brand-assets.html) · [Kotlin Foundation usage guidelines](https://kotlinfoundation.org/guidelines/) · [Kodee reference image](https://commons.wikimedia.org/wiki/File:Kodee-mascot-regular.svg) | Purple body, black rectangular face, large white eyes, arms and legs. Kodee is the official Kotlin mascot and is licensed CC BY 4.0; attribution: “Kodee by JetBrains s.r.o.” |
| Swiftie — Swift | [Apple Developer — Swift resources](https://developer.apple.com/swift/resources/) · [Swift logo reference](https://meta.wikimedia.org/wiki/File:Swift_logo.svg) | Orange/red stylized swift bird mark. This is a language logo, not a separate animal mascot; Swiftie is a CodePaws interpretation. |
| Camel — Perl | [Perl logo — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Perl-logo.svg) | White camel silhouette on a blue circular field. Perl's camel is a logo/brand symbol, not a detailed official character mascot. |

- Ferris: original artwork by Karen Rustad Tölva; the Rust artwork project describes it as CC0/public-domain-dedicated where possible.
- Kodee: created by JetBrains; CC BY 4.0. Suggested credit: “Kodee by JetBrains s.r.o. is licensed under CC BY 4.0.”
- Duke: Java community material states that Duke was open-sourced under a BSD license; check the individual source asset's license before distributing that asset.
- PHP ElePHPant: character by Vincent Pontier; check the license of the specific illustration selected.
- Docker and GitHub assets are trademarks. Docker's trademark guidelines explicitly prohibit creating imitations/facsimiles of its logo or character. The CodePaws sprites are therefore original, low-resolution educational interpretations and are not official brand assets.
- Other logo references identify the technology visually. CodePaws does not bundle downloaded logo files.
