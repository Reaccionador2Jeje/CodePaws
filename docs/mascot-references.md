# CodePaws — mascot and logo visual references

These are visual research references for the five hand-drawn 48×48 terminal sprites. The adoption catalog includes programming languages and developer tools with recognized mascots. Logo-only languages and non-language tools are intentionally excluded.

| CodePaws pet | Reference | What the reference establishes |
|---|---|---|
| Py — Python | [Python Software Foundation logo resources](https://www.python.org/community/logos/) | Blue and yellow interlocking snake mark. |
| Ferris — Rust | [Rustacean.net — original Ferris artwork](https://www.rustacean.net/) · [Rust artwork repository](https://github.com/rust-lang/rust-artwork) | Orange crab silhouette, shell, eyes and pincers. Ferris is Rust's unofficial community mascot; the original artwork is dedicated to CC0 where possible. |
| Gopher — Go | [The Go Gopher — official Go blog](https://go.dev/blog/gopher) | Renée French's gopher: blue rounded body, large eyes, ears, muzzle and front teeth. Go gopher artwork is CC BY 4.0; credit Renée French. |
| Duke — Java | [Dev.java — Duke, the Java mascot](https://dev.java/duke/) · [OpenJDK Duke gallery](https://wiki.openjdk.org/spaces/duke/pages/51282071/Gallery) | White character, pointed dark head and red nose. Java community material states that Duke was open-sourced under BSD; check individual assets before redistribution. |
| ElePHPant — PHP | [PHP.net — ElePHPant](https://www.php.net/elephpant.php) · [Wikimedia Commons — ElePHPant artwork](https://commons.wikimedia.org/wiki/File:Webysther_20160423_-_Elephpant.svg) | Blue elephant mascot with large ears and trunk. Original character credited to Vincent Pontier. |
| Moby — Docker | [Docker — Call me Moby Dock](https://www.docker.com/blog/call-me-moby-dock/) | Blue whale carrying shipping containers. |
| Mona — GitHub | [GitHub Brand Toolkit — mascots](https://brand.github.com/graphic-elements) | Cat-octopus mascot. |
| Tanuki — GitLab | [GitLab Pajamas — Tanuki logomark](https://design.gitlab.com/brand-logo/logomark/) | Orange/yellow tanuki mascot identity. |
| Camel — Perl | [Perl logo — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Perl-logo.svg) | Camel symbol associated with Perl. |
| Kodee — Kotlin | [Kotlin brand assets — official mascot](https://kotlinlang.org/docs/kotlin-brand-assets.html) · [Kotlin Foundation usage guidelines](https://kotlinfoundation.org/guidelines/) · [Kodee reference image](https://commons.wikimedia.org/wiki/File:Kodee-mascot-regular.svg) | Purple body, black rectangular face, large white eyes, arms and legs. Kodee is the official Kotlin mascot and is licensed CC BY 4.0; attribution: “Kodee by JetBrains s.r.o.” |

## Attribution and trademark notes

- Go Gopher: designed by Renée French; CC BY 4.0. Credit is required when using Go Gopher artwork or derivatives.
- Ferris: original artwork by Karen Rustad Tölva; the Rust artwork project describes it as CC0/public-domain-dedicated where possible.
- Kodee: created by JetBrains; CC BY 4.0. Suggested credit: “Kodee by JetBrains s.r.o. is licensed under CC BY 4.0.”
- Duke: Java community material states that Duke was open-sourced under a BSD license; check the individual source asset's license before distributing that asset.
- PHP ElePHPant: character by Vincent Pontier; check the license of the specific illustration selected.

- Other logo references identify the technology visually. CodePaws does not bundle downloaded logo files.

This document is a visual reference index, not a grant of rights to third-party artwork or trademarks.
